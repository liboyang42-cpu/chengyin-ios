# Approved topic snapshot preparation

This source slice adds a separate, default-empty `approvedTopicReleasePrepare` capability for POST `api/approved-topic-release/v1/prepare`. Existing publishing/project grants do not authorize it. The ordinary completed professional editor offers the read only for a same-owner personal CITY submission with its consistent, durably retained V2 audit task acknowledgment. Historical submission facts remain distinct from the fresh server result.

The new server response contract `questify.topic-release.text-city.v1` is a captured readable projection of a currently verified approved audit snapshot. It includes exact audit and manifest hashes, source version, literal category IDs and ordered story/node references. It does not allocate a release. Answers and private guide contents are excluded from this author summary. Category IDs are descriptive metadata and do not grant permissions.

The UI displays server-captured values rather than re-reading the mutable draft. Every opening, read, close, sheet Binding and disappearance is fenced by its original presentation, editor incarnation, account/session and completed record. The flow owns and synchronously cancels its actual read task; queued repeated reads cannot replace that task. Late unauthorized responses cannot mutate another session.

The response is size/depth/token bounded before recursive parsing, and the existing lossless duplicate-key parser rejects escaped key aliases. Strict identities, profile, fields, hashes and node uniqueness are checked. This first contract accepts no media reference. Image reference text is never fetched. A future separately reviewed owned-asset contract must explicitly extend the supported profile; successful URL parsing or hashing a URL is not media proof.

The DEBUG synthetic source supplies deterministic server bytes through the actual HTTP adapter. One tests the actual Chinese accessibility5 environment. Eleven Core methods and four AppUnit methods cover identity, resource bounds, default-off composition and retained action/task lifetimes. These Swift tests have not executed on Apple tooling in this workspace.
