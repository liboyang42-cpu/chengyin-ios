# P034 story audio selection and explicit upload

This slice connects the ordinary personal professional chapter editor to the existing document upload contract. It depends on the accepted story-image topology successor; it does not change that frozen packet. The image documentation count is corrected here from its original 15 AppUnit methods to the cumulative 18, preserving the original image implementation and test bodies.

The Mini source first inserts an empty audio block, then offers one mp3, m4a or aac document for that exact block. Cancelling keeps the placeholder. The native Add audio action now saves that empty block through the existing local draft envelope before any picker opens. Choosing a document retains a bounded local copy, filename and measured size. Only the explicit Upload action sends it. Applying the returned reference fills the captured existing block and saves locally. Removing the block is an explicit local action. Empty placeholders remain local and are omitted by the unchanged story serializer.

The document reader reuses the existing coordinated read and security-scope lifetime. It opens only the provider's coordinated regular file, refuses symlinks, measures the 10 MiB limit in bounded chunks, checks cancellation and file changes, and releases copied bytes on cancellation. It retains no provider URL, file descriptor or bookmark. The existing template metadata-only adapter remains unchanged. File extensions and byte counts do not establish decoding, playback or duration; this slice has no audio player or microphone permission.

The existing POST `api/common/uploadOSS` receives exactly fileType, fileName and one file body. An independent, default-nil audio approval binds account, deployment, origins and native picker permission. Image approval cannot authorize audio. Ordinary AppSession source factories and the outer transport capture viewer and synchronous project-configuration generations, including clone responses. A source-readable URL response is a legacy reference, without asset ownership, content version, review approval or release eligibility. The text-only W02 release compiler remains unable to publish audio dependencies.

Before dispatch, a separate per-draft local journal saves an attempt and exact target. A received reference that cannot be persisted remains an independent recovery fact within the current AppSession; reopening offers local receipt persistence without another upload. A result with no saved response remains unknown. This legacy API has no upload-status or idempotency contract, so it is never automatically retried. A new explicit selection creates a new attempt. The journal stores neither document bodies nor credentials.

Targets bind owner, draft identity, chapter and original block, exact draft bytes, editor incarnation, structure lease and monotonic story topology revision. A moved, deleted, reordered-and-restored block, changed account or retired presentation cannot receive a late callback. The ordinary same-block apply does not rotate topology. Local save failure leaves the editor's prior draft visible; partial envelope persistence and receipt-marker failure can retry locally without creating a duplicate block or sending again. Filenames are optional local metadata bound to the exact reference; they are not added to the existing server payload. Prepared review renders only audio references already captured in its payload, in their final serialized order.

DEBUG fixtures use generated opaque bytes and an in-memory response through the actual bounded client. They do not open a document provider or perform an upload. New authored coverage includes 18 Core methods, 25 AppUnit methods and two complete UI methods. The complete UI estimates are 900 seconds each, unmeasured, in separate direct XCTestCase classes; inherited complete costs and observations remain historical and must be reconciled centrally once. Source contracts, Tree-sitter parsing and project checks are supplementary; Swift typechecking, Apple API validation, XCTest execution, real provider behavior, backend upload and playback remain unverified here.
