# 小程序 ↔ iOS 对齐（C 区：活动 / 发现内容 / 票与订单 / 主题 / 广场）

更新：2026-10-19 UTC。分支 `cloud/align-C-20261019`，基于 `migration/native-ios@27d2854`。

小程序 `liboyang42-cpu/hengyin/chengyinhub-xcx` 是产品真源。本页逐页对照 iOS 视图，并按 P0/P1/P2 给差距分级：

- **P0**：核心行为错误或缺失。
- **P1**：可见的文案、字段或布局不一致。
- **P2**：打磨项。

"已修" 只表示本分支有对应源码和测试，最终以 CI 结果为准，不代表业务验收、真机验证或服务端联调。

政策边界不变。真实报名、支付、退款、短信、OAuth 和线上写入，只能在离线 DEBUG 夹具中出现。凡是要求这些的差距，一律标为 **policy-blocked**。
