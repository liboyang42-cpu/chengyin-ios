# Picture answer composition (P036)

Source: the master document's P036 `pickCorrectPicture`, `addAdvancedRow`, `updateAdvancedRow`, `removeAdvancedRow`; real Mini `temp-index.js` and `temp-index.wxml` 315–342. Mini displays a radio-like answer control and rewrites all `correct` flags on a selection, so tapping the chosen picture again cannot deselect it. The existing native generic editor offered independent per-row switches instead.

The existing pricePair items destination now offers one complete list: add a picture, edit its name and optional address, select the sole answer, reorder, remove, inspect current answer count and existing validation. Title, score and attempt controls stay on the existing parent. Reordering is retained native behavior; Mini does not define a reorder event here. Existing local rehearsal and save/restore read the same `pricePair.items` array. New IDs and defaults deliberately reuse native `addCreatorRow`, because the imported Mini `ADVANCED_ROW_TEMPLATES` implementation is not available; this package does not claim exact parity for that helper's defaults.

Opening never selects, clears or normalizes anything. A selection explicitly sets the target `correct: true` and all others false. Removing a selected row leaves no answer and existing validation tells the author to choose again; there is no inferred replacement. The editor preserves unknown fields, names/addresses, other game fields and other families. Malformed legacy lists use the original generic editor. Raw names/addresses are not truncated, and the existing 3–8 item, name-length and media-address rules still apply. No image fetching or upload happens.

Local occurrence UUIDs prevent duplicate labels or malformed duplicate wire IDs from retargeting controls. Structural actions retire old bindings. Actual external draft emissions, restore, owner/media changes, locks and dismissal fence writes. Parent review/revision-only `changed()` refreshes do not interrupt typing. Exact JSON bytes distinguish canonically equivalent Unicode spellings. External draft replacement requires an explicit reload. Local row IDs are not persisted.

Integration: register the App/Core sources and App XCTest from `docs/registration/template-picture-choices.json`; merge the 14 localized keys from `docs/localization/template-picture-choices.json`. Apply the shared-view patch as an increment, never overwrite a previously combined view with this package's standalone after file. There are no prior-package dependencies.

Tests: Core and App XCTest cover the complete edit chain, repeated answer tap, no replacement on removal, ID allocation, malformed fallback, preservation, stale controls, parent refresh, local save/restore and existing rehearsal. Without Swift/Xcode they are NOT_RUN. Python source checks and Node original Mini-event checks are supporting evidence, not native compilation or runtime validation. No real player gameplay, backend save or reward execution is part of this feature.
