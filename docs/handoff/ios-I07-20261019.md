## Findings and changes

1. **Leaderboard filters were never received (iOS bug).** `ApiGrowthController.leaderboard` binds `LeaderboardQueryDTO` without `@RequestBody`, and the mini-program (`subpackageP3/pages/growthcenter/leaderboard`) posts it through the default urlencoded request client. iOS sent a JSON body, so the server ignored `metric/period/limit` and always returned point/total Top 50; iOS then (correctly) refused the mismatch, so the week and EXP tabs always showed an error. `GrowthCenterService.leaderboard` now sends the three values as form fields; the other three growth reads keep their `{}` JSON body.
2. **Unranked is not 0 points.** `GrowthServiceImpl.buildMe` fills an unranked viewer (no rank row, or no ranked members) with `score: 0` and `rankPercentage: "TOP100%"`. The service now drops those placeholders when `rank` is null/non-positive, so the growth center score card and leaderboard show unknown instead of a fabricated 0. New `GrowthLeaderboardStanding` (`listed` / `outsideList` / `unknown`) keeps a real rank and score outside the returned Top N (for example rank 87 of a Top 50 board).
3. **Denied is distinct.** `ProfileReadFailure.isDenied` (403 by HTTP status or envelope code) separates a refused wall from sign-in (401) and from an empty wall. A refused or failed medal read still keeps the established identity cards as a partial wall (existing behavior, now covered for 403).
4. **Two accounts.** Covered that an in-flight account-A badge wall is discarded when the session changes to account B, does not trigger A's sign-out, and B's read is fresh with B's token (no cached cross-account wall).
5. **Points.** No source change was needed: `ledger(.assetPoints)` already sends no page fields, refuses page > 1 before dispatch and offers no load-more; `ledger(.points)` always sends `pageNum/pageSize` and keeps table totals. Added a contract test that neither surface accepts the other's wrapper. `Core/WalletCommerceService.swift` was not edited (w2-05 #23 changes it).
6. Play companion board (`api/play/leaderboard`): already keeps the real completion count with a null rank outside its Top 50; covered.
