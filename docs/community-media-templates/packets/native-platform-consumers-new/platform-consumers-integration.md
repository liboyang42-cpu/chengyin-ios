## Runtime enablement requirements (not performed)

Provide exact normalized HTTPS approved origin strings (`https://cdn.example.com`, non-default port if applicable). Empty allowlist refuses all media. URL userinfo, non-HTTPS schemes, fragments and unapproved origins are rejected. The user reviews the selected origin before a fetch; source/scope replacement and background reset consent. Do not infer approval from the server returning a URL. No cookies, auth headers, stored credentials or cache are used. Every HTTP redirect is checked against the same allowlist. Invalid status, timeout, size over 20 MiB, decoder failure and interruptions are failures/stops. Buffered finite audio only: HLS, live streams, duration scrubber, recording, transcription, IM, generated/NPC TTS and lock-screen controls are excluded.

External Maps review explicitly identifies the destination and recipient Apple Maps. The OS adapter opens the destination pin only; it does not request current location or supply a live origin. Missing coordinates (including source zero sentinels, nonfinite, out of range) never invoke Maps. Launch failure offers a separate Copy action, so clipboard changes are explicit rather than automatic. Copied, launch failure, copy failure and missing-coordinate UI are different states. No map result asserts arrival or a completed navigation journey.
