## Summary

- Pages in scope: 35 (27 `pages/merchant/*`, 8 `pages/coop/*`). Rows written: 35, plus the coupon manager. Pages remaining without a pass: 0.
- Biggest gaps that need logic, not UI: coop invitation / perk / deposit writes (reviews end at a disabled submit), city node and game-node station writes (`permitsWrites`), prediction settlement, store-character voice recording, workbench data the mini shows but native does not load (business open/closed, project cards, inbox preview), 关系 tab feed + club cards.
- Nothing in scope forces a colour scheme; merchant roots set `.themeDomain(.merchant)` once.
- Builds were not run in this lane (no Swift toolchain here). Edits keep existing signatures; new strings were added to `Resources/Localizable.xcstrings` (en + zh-Hans) or edited in the existing per-feature tables.
