# UI lane D4 — Club

| Mini-program page | Native file | What changed | What remains | Needs backend or logic |
|---|---|---|---|---|
| pages/talent/list | App/ClubHomeView.swift, App/ClubTabParityViews.swift, App/ClubCommunityViews.swift | Title is 发现 / Discover when the 帖文 / 俱乐部 tabs show, as in the mini-program. Clubs are one list again (created → joined → nearby), with no group headers and no three separate empty rows. A single `ContentUnavailableView` 还没有俱乐部 replaces them, without the explanatory caption. Merchant view: the loading and unconfirmed-city states lose their captions; the "ready" caption becomes the list's section header 同城俱乐部 / Clubs in your city; the empty row reads 本城还没有俱乐部. | pages/club/apply | App/ClubGovernanceViews.swift (`ClubGovernanceReadView` `.hostStatus`), App/ClubGovernanceCommandForm.swift (`.hostApply`) | The host-status screen no longer shows raw `accountRole` / `registered` values or the contradictory "Host submission isn't available right now" line next to a working Apply button.
