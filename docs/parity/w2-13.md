## Reform plan v9 §U01 (image and video media)

- New `Core/ProjectTopicMediaUploadPlan.swift`: the eight stages (selection, processing, upload, moderation, save, recovery, read, playback) are reported separately; only selection/processing/recovery are local, upload is disabled, the rest have no server contract.
- Stable request ID per draft + content digests, so a retry after an uncertain outcome reuses it; an uncertain outcome blocks a resend until a readback with the same request ID resolves it.
- Upload is blocked unless a reviewed per-market path is supplied **and** the flag is on. Defaults: no path, flag off.
- `App/ProjectTopicMediaStageSummary.swift` shows the per-stage status in the topic media section. Video is still not selectable, and its URL never goes into `imgUrl`/`imgArr`.
- Not done: real upload/moderation/readback contract (none exists in the mini or backend for topic video), playback.
