## U01 post media chain (reform plan v9 U01)

The mini-program is image-only (no `chooseVideo`, `mediaType:'IMAGE'` hard-coded), so video is new App scope.
Backend facts: `CommunityPostServiceImpl.registerMedia` accepts `VIDEO` (≤ 200 MiB, width/height/durationMs, upload
receipt required); the only upload transport `api/common/uploadOSS` is JPEG/PNG only.

| Step | iOS | Status |
|---|---|---|
| select | existing PHPicker (`.images, .videos`); `SquarePostMediaFileRegistry.copyMovie` copies a movie inside the provider callback, bounded and hashed | done (needs a policy) |
| process | `SquarePostVideoInspector` (AVURLAsset duration/tracks/size/playable, poster frame) | done |
| check | `SquarePostVideoInspection.rejections(policy:)`; missing policy = unavailable, never unlimited | done |
| upload | `SquarePostVideoUploadAvailability` = unavailable (`noReviewedVideoUploadEndpoint`); button disabled with reason | **disabled by design** |
| review | `SquareMediaReviewState` (APPROVED/PENDING/REJECTED/UNAVAILABLE, reason) on read rows | done (read) |
| register | `SquarePostVideoRegistration` body for `api/v1/community/media/register` (VIDEO) | dormant, never sent |
| save / restore | `SquarePostMediaDraftStore` account+draft scoped manifest; restore re-hashes files → ready/changed/missing | done |
| read | `SquarePost.videos` from `media[]` VIDEO rows | done |
| play | `SquarePostVideoPlayerRow`: explicit tap, https sources with a host only, AVKit `VideoPlayer` | done |

Production injects no video policy, so the existing composer keeps its "video unavailable" row (its tests unchanged).
Offline fixture: `--uitesting-module square --uitesting-square-scenario mediaChain` (`SquarePostMediaFixtureHost`).
Decision needed: a reviewed video upload transport and production video limits (size, duration, formats).
