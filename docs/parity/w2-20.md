## What changed

- **Tabs (alignment P0-3 fixed).** `IMInboxTab`/`IMInboxSummary` reproduce `tabOf`: 私信 = type 1 + 3 (+ absent/unknown, `parseInt(type)||1`), 系统 = type 2. Per-tab badge counts exclude muted rows (same rule as server `unreadTotal`). The mini-program hides type 4 groups because WeChat owns groups and its source comment reserves groups for the native app, so iOS shows a third 群聊 tab only when the server returns a group row (decision D3). Default tab 私信; a snapshot containing only groups opens on 群聊.
- **Row**: system bell avatar, name with source fallbacks, 官方 tag for type 3, mute mark, China-anchored time text (`fmtTime`: 刚刚 / N分钟前 / HH:mm / 昨天 / 周X / M月D日), unread badge with `99+`, quiet badge when muted.
- **Row actions**: existing 标已读 / 免打扰 plus new **删除 (hide)** → `/api/im/delete {conversation_id}` with the `im.conversation.delete` danger copy; acknowledged hide rereads `/api/im/conversations` before the row disappears.
- **Read-all** disabled when no visible row has unread (`hasUnread`).
- **Empty states** per tab with source copy; 去广场找人 only on an empty 私信 tab when Square is granted.
- **Chat 更多 menu** (`IMSafetyMenu`): 举报 / 拉黑 or 解除拉黑 / 隐藏会话; system notices offer only 隐藏会话. Report targets the latest server message from another member (never own, system or pending rows) with `reason=用户举报`. Block/unblock resolve the peer from a fresh `/api/im/conversations` read (type 1, counterparty id > 0 and ≠ self), as the source does.
- **Composer gate**: `MessagingPage` now decodes `blocked`/`blockedByMe`; `IMReplyBlock` shows 你已拉黑对方，无法发送消息 / 对方暂不可联系，无法发送消息 and withholds the composer and media controls. Block/unblock success rereads the page instead of assuming state.
- **Closed hangout**: `HANGOUT_CLOSED` shows 这个组局已结束 + 返回消息列表.
- **Time dividers**: `IMInboxTime.dividers` reproduces `decorate` (first message, then gaps > 5 min; 今天 HH:mm / 昨天 HH:mm / M月D日 HH:mm).
- **Unread entry badge**: `IMUnreadTotalReader` (`/api/im/unread-total`, no fields, `data || 0`) behind new feature `imUnreadTotal`; shown on 我的→消息 and a new club-tab toolbar 站内消息 icon (`SessionMessagingToolbarEntry`), which opens the same session messaging home. Failure or no grant shows no badge, as in the source.
- **Copy**: 79 bilingual keys in `docs/im-messaging-localizations.json`, merged by `tools/add_im_messaging_localizations.py` (idempotent; re-run after catalog conflicts). Six existing zh strings aligned with source copy (closed / missing / sign-in hint / system-notice reply).

New runtime features (all empty by default): `imDelete` → `api/im/delete`, `imReport` → `api/im/report`, `imBlock` → `api/im/block`, `imUnblock` → `api/im/unblock`, `imUnreadTotal` → `api/im/unread-total`.

## Decisions needed from the user

- **D1 preview text** – iOS deliberately drops `lastMsgText` because the conversation row has no recall/status provenance; rows show 打开会话查看消息. The mini-program shows the preview. Keep, or accept the server preview?
- **D2 read receipt + polling** – the mini-program marks read on every load and polls every 8 s while visible. iOS keeps explicit 标已读 and manual refresh (no timers, no implicit writes). Allow automatic `/api/im/read` once `imRead` is granted?
- **D3 group tab** – iOS shows 群聊 when groups exist (mini hides them; its comment reserves groups for the app). Confirm.
- **D4 report confirmation** – the mini-program reports in one tap; iOS adds an explicit review (write policy). Confirm copy.
- **D5 grants** – all new writes and the unread badge need reviewed per-market routes before they do anything.
