## pages/club/detail — partial (P045)

| | |
|---|---|
| Mini-program | `pages/club/detail/index.{js,wxml}` (`PUBLIC_TABS`, `tabsForClub`, `defaultTabForClub`, `switchTab`, `loadClubAccess`, `loadLeaderboard`) |
| iOS | `App/ClubDetailView.swift`, `App/ClubDetailTabBar.swift`, `Core/ClubDetailTabs.swift` |
| Tests | `Tests/CoreTests/ClubDetailTabTests.swift`, `Tests/AppUITests/ClubDetailTabsFlowTests.swift`, `Tests/ContractChecks/test_club_detail_tabs.py`; tab steps added to `ModuleFlowTests` and `ClubManagementFlowTests` |

Done in this lane:

- `cy-tabs.club-view-tabs` → `ClubDetailTabBar`: 帖子 / 活动 / 概览, plus 管理 when `canGovern`
  (owner or `viewerIsAdmin`) or `/api/club/access/me` grants any manage permission
  (`club:write`, `club:member:approve|manage`, `club:content:manage`, `club:role:manage`,
  `club:notify:send`, `club:activity:manage`, `club:event:operate|checkin`, `club:finance:read`)
  or an event scope. Access failure or a foreign club revokes to the legacy flags
  (`revokeClubAccess`); account change clears the grant and selection.
- Default tab: owner/member → posts, guest/merchant viewer → overview (`defaultTabForClub`).
  A `tab=manage` intent (`requestedTab`) is honoured only once the detail read confirms access;
  gated tabs cannot be forced and re-selecting is idempotent (`switchTab`).
- Tab content: posts → club chat + `ClubCommunityEntry`; events → `/api/club/topics` list/calendar
  (`ClubEventCalendarView`) + session quick start; overview → introduction, leader/city/type,
  members (gated), 本团贡献榜 · 本周 (`/api/club/leaderboard` via the existing read, locked copy
  for non-members), 治理与安全 note; manage → AI design, project launch, merchant discovery,
  invitation feedback, lead progress, stats, governance workspace, operations, management.
- Non-managers keep the governance workspace entry on the overview tab (cases/appeals).
- Explicit unavailable copy when a host has no community or governance context.

Gaps:

- Events tab shows a link to the list/calendar instead of inline event cards (`ev-card`).
- Overview facts are rows, not the 3-up 主理人 / 等级 / 所在城市 grid; 邀请成员 share is absent (no share sheet in scope).
- Manage tab: owner stage card (`OWNER_STAGE_COPY`), editions share, coop pool apply
  (`/api/coop/pool/apply`, a write) and the tools grid (customers, enroll, settlement, notify,
  roles) are reached through the governance workspace rather than inline folds.
- Posts tab composer/like/pin/history/report actions are covered by the existing community lane, not re-audited here.
- Deep link `tab=manage` is not yet passed by any iOS entry (settings/workbench entries live in other lanes).
