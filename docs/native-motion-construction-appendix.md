## 通用按钮按压与真实处理中

### 按压

适用：已有自定义可点击卡片与自定义主操作。直接复用既有ButtonStyle：按下约120ms、缩放到0.98，释放约240ms，克制弹簧；触发动作发生在正常按钮激活时，不等动画结束。系统Button、NavigationLink、Menu已提供的反馈不再重复包一层。

不适用：禁用控件、只读信息、正在滚动且已取消的按压、被权限门禁阻止的动作。不能用DragGesture取代Button语义以制造按压感；滚动时手指移出应取消激活。连续点击不能排队多个动画或多次写请求。

SwiftUI接法：保留Button/NavigationLink身份及ButtonStyle的 `configuration.isPressed`；动画仅绑定局部按压状态。命中范围至少44pt，不用视觉缩放缩小命中范围。导航、取消和返回不依赖动画完成回调。

### 处理中与结果

R14只提供视觉参考。按钮是否可提交、请求是否可取消、失败是否允许重试、未知结果如何恢复，全部读取已有协调器合同；不在视图内建立竞争的业务状态机。

| 既有业务状态 | 呈现与交互要求 |
| --- | --- |
| 可操作 | 显示真实动作名，不提前展示成功符号 |
| 请求进行中 | 同一按钮局部切换ProgressView及“处理中”语义，立即防止同一请求重复提交；保留原有允许的返回/取消能力 |
| 已知成功 | 只有既有权威结果确认后显示完成，至多一次局部符号反馈；页面加载或重复读到旧成功不得重播 |
| 已知失败 | 保留输入、选择及失败原因，按合同提供明确重试；不全页摇晃，不闪红整屏 |
| 结果未知 | 明示未确认；不能当失败自动重发，也不能当成功庆祝。沿用已有查询/恢复/锁定路径 |
| 本地取消或页面离开 | 不推断服务端已取消。取消是否阻止网络、是否保留恢复记录按现有合同；迟到结果不得覆盖新页面或新账号 |

SwiftUI接法：使用现有协调器公开状态映射同一局部容器；稳定标签高度和命中区域，必要时让文字自然换行。`Task`和回调的生命周期仍属于原业务所有者。离开、账号切换和新版请求使旧视觉回调失效。没有真实进度值就用不定进度，不插值成百分比。

## 列表与卡片进出

适用：已有列表经确认出现一条新记录、现有合同确认移除、一个已加载图像替换占位、当前badge状态变化。优先复用局部180ms opacity，不改变响应排序、重复ID语义、分页、筛选结果或选中项。

不适用：初始整屏大规模交错入场、每次滚动重播、整张列表因图片加载而弹动、刷新时全部移除再插回。未知、部分、空和失败状态各自显示，不用空列表过渡掩盖权限失效或加载错误。

SwiftUI接法：沿用数据域已定义的稳定行身份；不能假设服务端ID全局唯一，也不能在body里生成UUID。默认保留List/LazyVStack系统更新；如需要局部transition，只作用于已识别的变化行，不向上层绑定整个数组的动画。媒体大图回位时保持原滚动位置和稳定选中身份；无身份连续性就淡入，不强行matched geometry。删除期间保留必要的占位和焦点落点；业务确认、Undo与失败行为不由过渡推导。

## 展开收起与详情呈现

适用：现有章节说明、辅助信息、筛选选项、集合点摘要以及已有中/大尺寸详情sheet。普通内容优先DisclosureGroup；已有sheet优先 `presentationDetents`，由系统处理拖拽和中断，不为模仿网页重做原生呈现。

局部展开建议240–300ms，高度随内容自然变化；只有确实存在共享元素与稳定身份才考虑自定义圆角/宽高morph。打开与关闭互为可中断操作，反复点击应以最新状态为准。隐藏内容不得继续接受点击或获得VoiceOver焦点。

选择器关闭时回到原触发控件；详情内的失败与重试不能锁死关闭手势。输入框、键盘、焦点和已填草稿不因展开销毁。大字下允许变为垂直排列、全高sheet或系统选择器，不能固定高度裁掉按钮。

不适用：有完整解释义务的危险操作、法律/支付确认、会话恢复、结果未知读回。它们继续使用既有系统alert/sheet与合同，不用一个快闪morph取代审阅。

## 数字变化

适用：既有数量Stepper、已有已选人数、已知计数与进度。建议180–240ms，同一行内数字等宽，变化方向与增减一致。业务值先成为事实，动画只展示从旧值到新值；新的值到来时从当前显示继续收敛，不串行播放过时数值。

SwiftUI接法：iOS 17 `contentTransition(.numericText(...))` 配合局部withAnimation或value动画和monospacedDigit；原生Stepper保留可增减的辅助功能动作。规范只建议API路线，不给组件代码。金额与ID使用既有精度安全的值及格式化文案，不能为了动画转成Double造成精度损失。未知、不可用、部分结果保持明确文字，不能先滚到0或100%。

边界：上下限由既有合同决定。达到上限时提供文字解释与语义禁用或已有反馈，不要求复制R19的抖动。读屏只公告最终业务值，不逐帧播报。倒计时必须来自已验证时区与时间边界，不给每张卡装装饰性一秒计时器。

## 建议时长与原生实现顺序

以下均为本项目建议调参范围，不是原片实测，也不是Apple规定值。已实施的参数优先复用，不为统一表格改动已经验证的页面。

| 动作 | 起始建议 | 优先方式 |
| --- | --- | --- |
| 自定义卡片按下/释放 | 120ms / 240ms，现有0.98缩放和0.08 bounce | 既有QuestifyCardButtonStyle |
| 图片、badge和局部行内容更新 | 180ms，必要时在120–180ms内微调 | 现有QuestifyMotion.content和opacity |
| 按钮文案、处理中状态切换 | 160–220ms | 同一Button内局部内容与ProgressView |
| 局部Disclosure | 240–300ms | DisclosureGroup及可中断原生动画 |
| 必要的较大自定义容器 | 280–420ms | 先验证系统sheet/导航能否满足，能满足就不自建 |
| 数字变化 | 180–240ms | 等宽数字和numericText |
| Reduce Motion | 默认立即更新；确需连续性时短淡入不超过约120ms | 先沿用既有QuestifyReduceMotion策略，去位移/缩放/弹跳/旋转 |

实现顺序：系统默认 → 现有通用样式/状态映射 → 小范围SwiftUI过渡 → 证实存在平台能力缺口后再讨论UIKit。没有新增动画库需求。系统sheet与NavigationStack的实际时序由OS控制，不用本表强制覆盖。

## 无障碍与大字

- Reduce Motion必须读取真实系统偏好，复用 `QuestifyReduceMotion`。现有DEBUG开关只作合成策略输入，不宣称切换了系统设置，不写只读environment值。去掉自定义飞行、旋转、缩放、视差、粒子与闪光；用立即更新或必要的短淡入保留信息。
- VoiceOver保留Button、Picker、Stepper、Disclosure等语义。装饰隐藏；状态含文字，不能只靠颜色、数字滚轮或触感。展开、选择、失败、已送达等在状态真正改变后适度公告，避免读屏每帧重复。
- 对话框打开建立合理焦点、关闭回触发控件。危险确认先聚焦取消。行移除后焦点落到相邻可理解位置；加载和动画不能制造离屏幽灵控件。
- Dynamic Type至少覆盖默认、大号及最大辅助功能字号，中英文、长名字/长错误文案、窄屏、横屏。文字自然换行，优先垂直堆叠，不固定文本卡高度，不压小关键字体。
- 44pt命中范围与点击间距持续有效。提高对比度、深色模式、透明度偏好使用原有语义颜色/材料后备；待办、失败、未知和完成不能只用不同颜色区分。

## 失败重试与中断验收

本表是未来施工验收清单，目前没有新增自动化测试，也不声称这些场景已在城瘾通过。

1. 同一操作快速双击、按下后拖动滚动、手指移出、连续展开/收起：没有重复业务动作，没有排队延迟触发。
2. 加载中返回、关sheet、再打开、切换账号、刷新到新记录：迟到数据和动画不会污染新上下文；现有恢复和未知结果锁定不被视觉结束解除。
3. 已知失败保留用户输入/选中，重试遵循合同；结果未知只走现有读回/恢复，不自动重发。确认取消不冒充服务器撤销。
4. 空、部分、失败、未知与权限不可用独立可读；缺图/断网/慢网不造成布局跳跃，重要操作不藏在过场后面。
5. 本地动画结束、网络返回、业务确认分别观察。成功反馈只由真实成功触发一次；读取旧成功、回前台和重新挂载不重播庆祝。
6. 媒体预览可兼容图片/视频，独立合同另行施工；本附录验收不替代该合同。

## 性能与视觉验收

先在支持的最低设备档及常用设备档做Release实机检查，并记录设备、OS、构建提交、数据规模和动态偏好。固定截图只能验证静态布局，不能证明动画或帧节奏。

- 在主线程忙、快速滚动、分页、刷新、图片到达、交互中断、退后台再返回时录制实际过程。检查Instruments中的animation hitches、主线程开销和内存；不得把“目标60fps”写成未经测量的通过结果。
- 已有60Hz设备以16.7ms/帧、120Hz以8.3ms/帧作理解预算的参考；实际刷新率与系统调度可变，记录可重复的卡顿与相对基线，而不是以截图或单次平均值宣称全程达标。
- 不在body里解码大图，不为视差/光晕加入持续全局计时器。使用已有缓存和受控图片尺寸；离屏停止装饰动画，避免大量blur、阴影、粒子及同时matched geometry导致离屏渲染。
- 每项未来验收记录四种状态：静态布局已查看、动作/中断已运行、系统无障碍已运行、Release性能已测量。缺证据写NOT_RUN，不能把网页预览或纯源码检查当原生验收。
- 合并前确认仅目标功能采用唯一主方案，相关旧实现被复用而非复制；保留功能、导航、输入、权限、排序、未知结果与后端合同的既有测试要求。本次不运行或改动CI，不打断run130。

- [Apple数字内容过渡](https://developer.apple.com/documentation/swiftui/contenttransition/numerictext%28value%3A%29)：现有数字值的局部表现，不提供业务精度或成功语义。

- [Apple Reduce Motion](https://developer.apple.com/documentation/swiftui/environmentvalues/accessibilityreducemotion)：读取系统偏好，不能写入只读环境值。
- [Apple辅助功能焦点](https://developer.apple.com/documentation/swiftui/accessibilityfocusstate)：必要时管理打开、关闭与状态变更后的焦点，不滥用强制跳焦。
