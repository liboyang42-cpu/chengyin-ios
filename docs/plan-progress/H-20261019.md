# Agent H — world, market, game state (2026-10-19)

Branch `cloud/plan-H-20261019`, based on `migration/native-ios@f9486a5`. Scope source: reform plan v9 (cited by section / work package only; the plan document itself is private and is not copied here). Product truth for existing behaviour: the WeChat mini-program in `liboyang42-cpu/hengyin/chengyinhub-xcx` (read-only).

**Evidence level.** No CI was run, no Swift compiler is available in the Linux sandbox, and no Apple build, XCTest, simulator or device run happened. What was executed: `tools/generate_project.py`, `tools/check_scaffold.py` (PASS), the new `Tests/ContractChecks/test_reform_world_contracts.py` (8/8 OK), and the full `Tests/ContractChecks` Python suite before and after this change — the set of failing/erroring checks is byte-identical (all pre-existing, none introduced). Swift sources and Core tests were reviewed by hand only and are **authored, not run**.

**Later external evidence (2026-10-19, reported on PR #17 by the repository owner).** `swiftc -typecheck` of App + Core as module `Questify` (Xcode 26.6, iPhoneOS 26.5 SDK, arm64-apple-ios17.0, Swift 5 mode, DEBUG) at `f60245a` reported 0 errors. Not covered by that check: the Core test target, Release configuration, linking, asset catalogs, simulator/UI tests. The Core XCTests in this slice therefore remain not compiled and not run.

**What kind of change this is.** Every item below is a *client contract*: pure Foundation domain types plus Core XCTests, with no transport, no endpoint string, no persisted state and no UI. The plan's suggested operations (StartRun, SubmitAction, InstallLicensedMod, JoinMatchPool, VerifyReturnHome, RollCityRound …) are not reviewed server APIs in hengyin, so nothing was wired to the network. All features sit behind `ReformWorldCapabilities.disabled` (every switch OFF; `meetingNFC` cannot be enabled even in DEBUG fixtures). No prices, rewards, dice, coordinates, radii, cooldowns or limits were invented: server facts are injected; the only numbers present are the plan's own part C qmod size proposals, carried in a profile flagged `isProposal: true`, and clearly-labelled synthetic values inside tests.

Status vocabulary: *not started* / *client contract only* / *UI wired offline* / *blocked on backend* / *blocked on decision*.
